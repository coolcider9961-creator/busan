# 부산 호스텔·외국인관광도시민박업 상권분석 시스템

서면(부전·전포)을 1차 중심으로, 부산 주요 상권(부산역·남포·광안리·해운대)으로 확장 가능한 **지속 업데이트형 경쟁사·객단가·고객층 분석 프로그램**입니다.

## 핵심 기능

1. **공공데이터 인허가 모수 수집 (`호스텔업` / `외국인관광도시민박업` 2종 구분)**
   - 공공데이터포털 Open API 또는 LOCALDATA CSV 업로드를 통해 정확한 도로명주소, 인허가일, 면적, 영업/휴업/폐업 상태를 수집합니다.
   - Bessel 중부원점 TM(`EPSG:5174`) 좌표를 WGS84 위경도로 자동 변환하여 지도에 표시합니다.
2. **에어비앤비 실영업·객단가·리뷰 스냅샷 수집 (Apify 연동)**
   - 호스텔·게스트하우스·다인실(도미토리)·개인실 경쟁군 위주로 필터링합니다.
   - 매 실행 시 고정 기준일(**D+7 평일 1박**, **D+14 주말(토) 1박**) 1박 총액(청소비·수수료 포함)을 시계열 SQLite DB에 누적합니다.
   - 최근 리뷰 날짜 기준으로 `활성 영업` vs `저활성/휴면 의심`을 판별합니다.
3. **공공데이터 ↔ 에어비앤비 교차 매칭 & 수동 보정**
   - 영업신고번호·상호명 유사도·좌표 근접성을 기반으로 자동 매칭하며, 대시보드에서 수동 매칭 확정/해제가 가능합니다.
4. **주요 고객층 & AI 리뷰 인사이트 (Gemini SDK)**
   - 리뷰 언어권(한국어/영어/일본어/중국어/기타) 비율을 정량 계산합니다.
   - Gemini API(`google-genai`)를 연결하면 1인/커플/친구/비즈니스/가족 비중, 포지셔닝 태그, 강점·약점 및 창업 벤치마킹 포인트를 자동 추출합니다.

## 빠른 실행

1. `실행하기.bat` 더블클릭 (가상환경 생성 + 패키지 설치 + Streamlit 대시보드 실행)
2. 대시보드 `⚙️ 수집·업데이트 & 설정` 탭에서 API 키를 입력하거나 LOCALDATA CSV / Apify JSON을 업로드합니다.
   - 키 입력 전 기능을 먼저 확인하려면 사이드바의 **🧪 서면 데모 데이터 체험하기**를 눌러보세요.
